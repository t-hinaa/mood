# MoodTracker

## アプリ概要
日記やジャーナリングは続けられるか自信のない方に。
気楽に始められる気分管理ツール。
他の誰よりも自分自身を大切にしたい方に使用してもらいたい。
一緒に「できる」という自己肯定感を上げましょう。

## アプリを作った理由
私自身のために作成したアプリ。
アイデアはあるけれど、カリキュラムの進行、ミニアプリの作成、卒業制作を同時に行うと、とてもじゃないけど時間は足りないし、何よりキャパオーバーで挫折すると思うとらんてくんに言われた。私自身もそう感じるし仕方ないと、泣く泣くボツにしたアイデアを供養するために今回参戦。入門ステップ終了後にミニアプリを作成し始めたものの、アイデアが形にならずもやもやしている経験から、今回はとりあえず「アイデアが形になる」を優先。WEBやAIの力をふんだんに借りた「動くアプリ」を。

## できること（機能一覧）
### MVP
- 色で気分を管理
- メモ機能
- カレンダーで色を確認


### 今後実装する機能
- i18n
- 日付ごとの詳細をカレンダーから選択することができる(モーダル表示)
- ヘッダー、フッター
- スプラッシュ画面
- 統計情報の表示(グラフで傾向を確認、感情の分布)
- 感情の天気予報:気象データと過去のログ、スケジュールから予測する
(「水曜日の午後はイライラしやすいので注意」など)
- 医師や専門家への「提出用レポート」
(天気図のようなカレンダーをデータ化。どんなタイミングが不調になりやすいかを伝えやすくする)
- 予報から暮らしのヒントを提案
（明日は雨（憂鬱）天気予報」なら→「お気に入りの入浴剤を用意しておきましょう」など）
- 共有機能(「統計から〇〇さんは、午後から雨（気持ちが落ち込む）予報です」など)
- 検索機能
- アカウント化オプション(Googleログイン)
- 画像アップロード機能
- 今週のまとめなど
- 使用しているカレンダー、スケジュールアプリと連動
